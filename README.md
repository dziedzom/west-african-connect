# MiddlBrand Connect

Build a modern React + TypeScript web app called MiddlBrand — a marketplace for West African companies to find and bid on RFPs/tenders and bussiness ingernral get apired with the opportunties found through lead generation . Include:
Responsive homepage with hero section explaining 'We connect vetted companies to missed opportunities and earn 3% commission on wins'.
RFP listings page with search/filter by category (pharma, transport, etc.), location (Ghana/Nigeria), value range ($100k–$200k).
Company directory/sign-up form (collect name, expertise, location, email).
About page detailing how we match and facilitate ethically.
Contact form and footer with social links.
Use Tailwind CSS, shadcn/ui components, dark mode toggle, and clean professional design."
